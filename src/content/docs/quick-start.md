# Quick Start

The short version, for anyone who just wants Cy360 running today.

## What you're installing

Cy360 is a Security Operations Center in a box: threat detection (SIEM), attack-surface monitoring, endpoint protection, and an on-premise AI assistant — all in one dashboard, running entirely on servers you control.

## What you need

- A Linux server (Ubuntu/Debian) or a Mac/PC for evaluation, with Docker installed.
- 15–20 minutes.
- No credit card for the Community edition.

## The three steps

1. **Pick a version.** Go to [Download](/download) and choose "Latest" (recommended) or a specific release.
2. **Run the install command.** Copy it, paste it into your server's terminal, and let it finish — it installs Docker if needed, pulls the images, and starts the stack.
3. **Log in.** Open your server's address in a browser and sign in with the default admin account shown in the [Deployment Guide](/docs/docker-deployment) — then change that password immediately.

That's it — Community edition is free forever and covers the full core stack. If you outgrow it, [Enterprise](/editions) adds more users, more monitored devices, and CyMind AI without needing a fresh install — just a license file.
